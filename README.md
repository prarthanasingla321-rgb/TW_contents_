Documentation of What I Have Learned in Technical Writing (TW)

This repository contains documentation and practical learning materials from the Technical Writing (TW) course.

Topics Covered

LaTeX – Document preparation, formatting, mathematical equations, tables, figures, and references.

Beamer – Creating professional presentations using LaTeX.

Doxygen – Generating software documentation from source code.

Google Docs – Creating, editing, formatting, and collaborating on online documents.

Git and GitHub – Version control, repository management, branching, merging, and collaboration.

# Google Docs Documentation

## 1. Introduction to Google Docs

Google Docs is a cloud-based word processor that is part of Google Workspace. It enables users to create and edit documents collaboratively in real time from different devices.

It supports:
- Comments and suggestions
- Version history
- Templates
- Integrations with other tools

Google Docs is useful for collaborative editing, general documentation, reports, proposals, meeting notes, and other non-code documents.

## 2. Key Features of Google Docs

### 2.1 Real-time Collaboration
- Multiple users can work on the same document at the same time.
- Edits made by collaborators can be seen as they happen.

### 2.2 Rich Formatting
Google Docs supports:
- Styles and headings
- Tables
- Images and drawings
- Links
- Equations

### 2.3 Comments and Suggestions
- Comments make it easy to provide feedback.
- Suggesting mode allows reviewers to propose tracked edits.

### 2.4 Version History
- Tracks changes made to a document.
- Allows users to view and restore previous versions.

### 2.5 Import and Export
Google Docs supports importing and exporting formats such as:
- DOCX
- PDF
- ODT
- RTF
- HTML
- TXT

## 3. Creating and Structuring a Document

A document can be created from a blank document or from a built-in template.

Examples of templates include:
- Reports
- Meeting notes
- Manuals

For a well-structured document:
1. Use headings and paragraph styles to organize the content.
2. Insert tables when information needs to be arranged or compared.
3. Use lists to present points clearly.
4. Add images when visual explanation is useful.
5. Insert footnotes and equations when required.

## 4. Paragraph Styles and Hierarchy

Google Docs provides paragraph styles such as:
- Title
- Subtitle
- Heading 1
- Other heading levels
- Normal Text

### Why are paragraph styles useful?
- They create a consistent appearance throughout the document.
- Proper heading styles allow Google Docs to generate a table of contents automatically.
- They support accessibility features.
- They improve document exporting.

A logical heading hierarchy also makes long documents easier to navigate.

## 5. Collaboration and Sharing

The **Share** option allows users to invite collaborators through their email addresses or a link.

Access permissions can be specified as:
- **Viewer:** Can view the document.
- **Commenter:** Can add comments.
- **Editor:** Can make changes to the document.

Other collaboration features include:
- Adding, resolving, and assigning comments.
- Using Suggesting mode for tracked edits.
- Using integrated chat for live discussions.
- Seeing live cursors and changes while collaborating on the same document.

## 6. Version History and Recovery

Google Docs automatically saves changes made to a document.

To view or restore an earlier version:
1. Open the document.
2. Go to **File → Version history**.
3. View the available versions.
4. Select a previous version if you need to restore it.

Specific versions can also be named for important milestones, such as:
- Submission
- Approval

Version history helps track document changes and recover earlier content.

## 7. Images, Drawings, and Diagrams

Google Docs allows visual content to be added to documents.

### 7.1 Insert an Image
Use **Insert → Image** to add an image from:
- Upload
- Camera
- Web
- Google Drive
- Google Photos

### 7.2 Insert a Drawing
Use **Insert → Drawing** to create simple diagrams using shapes and arrows.

### 7.3 External Diagram Tools
Extensions and integrations can support tools such as:
- Lucidchart
- diagrams.net

Images and diagrams can make explanations easier to understand.

## 8. Tables and Lists

### 8.1 Tables
Use **Insert → Table** to organize information.

Tables are useful for:
- Organizing data
- Comparing options
- Creating schedules

### 8.2 Lists
Google Docs supports:
- Bulleted lists
- Numbered lists
- Checklists

Lists help structure information, while checklists can be used for action items and collaborative tracking.

## 9. Equations and Code Snippets

### 9.1 Equations
Use **Insert → Equation** to enter mathematical expressions. Google Docs supports basic LaTeX-style mathematics through its equation interface.

### 9.2 Code Snippets
- Use a preformatted or monospace font for short, inline code snippets.
- For larger code blocks, use third-party add-ons or paste images, as described in the lecture slides.

## 10. Templates and Formatting Tools

Google Docs provides built-in templates for documents such as:
- Reports
- Project proposals

Formatting tools include:
- Customizing headers and footers
- Adding page numbers
- Find and replace
- Spelling and grammar tools
- Suggestive autocorrect

Templates and formatting tools help maintain consistency and save time.

## 11. Citations and Bibliography

Google Docs provides citation tools for adding references to documents.

Steps and features:
1. Open **Tools → Citations**.
2. Add source details.
3. Select a citation style, such as MLA, APA, or Chicago.
4. Insert in-text citations.
5. Generate a bibliography automatically.

Citation managers such as Zotero and Mendeley can also be integrated through add-ons.

## 12. Exporting and Publishing Documents

Google Docs supports downloading documents in formats such as:
- PDF
- DOCX
- ODT
- HTML

It also provides an option to publish a document to the web for public viewing.

Documents can be integrated with other Google Workspace applications, including:
- Google Slides
- Google Sheets

## 13. Security, Permissions, and Data Protection

Google Docs provides document-level permission controls.

The available controls described in the lecture include:
- Setting permissions for individual documents.
- Setting expiration dates for access.
- Removing access when it is no longer required.
- Workspace administrator controls for organization-wide sharing policies.

Permissions help control who can view, comment on, or edit a document.

## 14. Integrations with Other Tools

Google Docs integrates with several Google Workspace applications:
- Google Drive
- Google Calendar
- Google Meet
- Google Forms

It can also connect with:
- Project-management tools such as Trello and Asana
- Code tools such as GitHub
- Diagram tools through add-ons

Google Apps Script can be used for script-based automation.

## 15. Best Practices for Google Docs Documentation

The lecture recommends the following practices:

1. Use a consistent style guide and templates.
2. Organize content regularly with headings and a table of contents.
3. Assign reviewing and editing roles for major documents.
4. Clean up resolved comments and suggestions.
5. Back up versions and export important milestone deliverables.

Following these practices improves the clarity, consistency, and maintainability of documents.

## 16. Doxygen vs. Google Docs

| Feature | Doxygen | Google Docs |
|---|---|---|
| Purpose | Code/API documentation | General documents and proposals |
| Collaboration | Indirect, through code reviews | Real-time multi-user collaboration |
| Rich media | Diagrams in code | Images, tables, and drawings |
| Output | HTML, LaTeX, PDF, etc. | Web, PDF, Word, etc. |
| Best for | Source code and APIs | Policies, specifications, and notes |

## 17. When to Use Which Tool?

- Use **Doxygen** for automatic, up-to-date, code-linked API documentation.
- Use **Google Docs** for collaboration, business proposals, and non-code documents.
- Use **both together** for complete project documentation: design documentation can be maintained in Google Docs, while API documentation can be generated using Doxygen.

## 18. Practical: Google Docs Collaboration

The lecture suggests the following activity:

1. Create a Google Doc.
2. Share it with a classmate using Edit or Suggest mode.
3. Try headings, comments, and suggestions.
4. Add a table.
5. Embed an image or diagram.
6. Open version history.
7. Restore a previous version.

This exercise demonstrates document creation, formatting, collaboration, and recovery.

## 19. Key Takeaways

- Google Docs supports live collaboration, formatting, sharing, and version history.
- It is suitable for general documents and collaborative work.
- Documentation quality depends on planning, clarity, and selecting the right tool.
- Doxygen and Google Docs serve different purposes and can be used together.
